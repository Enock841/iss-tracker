# ISS Tracker

A Streamlit app that shows the International Space Station's current position and recent path on an interactive map.

## How to run

1. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Start the app:

   ```bash
   streamlit run app.py
   ```

3. Open the local URL that Streamlit prints in the terminal (usually http://localhost:8501).
